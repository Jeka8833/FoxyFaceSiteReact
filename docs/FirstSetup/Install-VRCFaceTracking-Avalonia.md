# Installing VRCFaceTracking on Linux or MacOS

1. Install [VRCFaceTracking](https://store.steampowered.com/app/3329480/VRCFaceTracking/) from Steam Store
2. Open the VRCFaceTracking installation settings (Click the gear icon, then select “Properties...”)<br />![OpenProperties](/images/FirsSetup/OpenProperties.png)<br /><br />
3. Select the version titled “Avalonia” (Go to the “Game Versions & Betas” tab, then select “Avalonia”)<br />![SelectAvalonia](/images/FirsSetup/SelectAvalonia.png)<br /><br />
4. Close the settings window and wait for VRCFaceTracking to update.
5. Launch VRCFaceTracking
